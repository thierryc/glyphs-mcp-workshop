# Provisional running order — not the final programme

Thierry and Rainer: choose the primary teaching client and rehearse the three
demos before finalizing timings. One person presents; the other handles setup
questions. All participants work on disposable copies.

| Minutes | Focus |
| --- | --- |
| 0–5 | Show an outcome in Glyphs |
| 5–15 | Request → AI → MCP → Glyphs; access versus guidance |
| 15–30 | Install, connect, identify the font |
| 30–45 | Inspect: prompt, demonstrate, try, review |
| 45–65 | Width preview, apply, inspect and undo |
| 65–70 | Pause and catch up |
| 70–85 | Better prompts; a small reusable skill/checklist |
| 85–105 | Read-only selection report; review, run, refine |
| 105–120 | Participant challenge, questions and next steps |

For each demo: starting checkpoint, copyable prompt, actual expected observations,
result capture and a short fallback recording. Keep recordings outside the
installable repository/archive. A recording is not a substitute for verification.

Do not promise remote installation of the private repository, identical behavior
in every client, automatic skill installation from AGENTS.md, arbitrary Python
execution over MCP, or unconditional undo after unrelated edits.
