# When something does not work

- **No connection:** check Setup's server status and your client card. Reload the
  client after configuration. Do not publish the local endpoint on the internet.
- **Wrong font:** stop before editing. Match the full workshop path; close duplicate
  workshop copies and identify the correct document again.
- **Missing Python:** install Glyphs' Python module and explicitly select the
  (Glyphs) runtime under Settings → Addons, then restart normally.
- **Dirty source:** save only the disposable workshop font after reading the
  prompt. Saving includes all changes in that font, not just the requested glyph.
- **Timed-out edit:** inspect the current workflow. Do not create another request
  under a fresh ID to “try again.” Preserve the report for the presenters.
- **Undo conflict:** stop. Review intervening edits; do not force a reset. Use a
  separate checkpoint copy for the next exercise after resolving the old state.
- **Empty script output:** select H and O in an Edit tab, run the script, and open
  the scripting output console. The script reads layers, not selected nodes.
- **Repository 404:** while private, sign in with an invited GitHub account.
  Anonymous downloads and the app's public catalog will work only after publication.
- **Template not listed:** extract the ZIP first, select the actual template folder
  through Add Local Template, then choose Use Template. The app copies rather than
  executes it; opening the repository webpage does not install a project.

Ask a presenter before changing versions mid-exercise. Never include API keys,
private font files or account details in a bug report.
